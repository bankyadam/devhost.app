disk-cleanup

      
Free disk space without losing anything: package caches and old Remote Control worktrees.

      
    
        
  • The Homebrew download cache
    • 
        
  • The npm cache
    • 
        
  • Old Remote Control worktrees — only when clean, every commit pushed, nothing running in them, and idle long enough
    • 
        
  • A doctor check warns when a lot is reclaimable
    • 
      

      preview firstasks before it deletesno --force
      
View on GitHub

    

    

      
Install

      
devhost plugin install \
  git@github.com:bankyadam/devhost-plugin-disk-cleanup.git --enable

      
Use

      
# sizes, and why each worktree stays
devhost plugin run disk-cleanup report
# free it (asks first)
devhost plugin run disk-cleanup clean [--dry-run]

🛑
session-stop

      
Win a few hundred MB back: stop the local claude process of a Remote Control session.

      
    
        
  • Stops only a process a devhost Remote Control service started, in that session's directory
    • 
        
  • Never touches the Claude app's sessions or anything else
    • 
        
  • SIGTERM first, SIGKILL after 5 s
    • 
        
  • The session stays in claude.ai's list; a new message there may start it again
    • 
      

      dry-runasks firstin the session's Open menu
      
View on GitHub

    

    

      
Install

      
devhost plugin install \
  git@github.com:bankyadam/devhost-plugin-session-stop.git --enable

      
Use

      
devhost plugin run session-stop stop \
  --session <id or first 8 characters> [--dry-run]

Build your own
A plugin is a small ES module.

  
No build step. It runs on your Mac server as you, and changes things only through devhost's own helper, so --dry-run and the plan work for plugins like for apply.

  

    
⚙️
Actions
Do something on the host, in an environment or in a session. They show up as buttons in the app.

    
🩺
Checks
Add your own lines to devhost doctor and the Doctor screen.

    
💡
Advice
Attach a note and a one-click fix under another check.

    
📊
Widgets
Cards on the dashboard: tiles, rows, meters, charts, with filters.
